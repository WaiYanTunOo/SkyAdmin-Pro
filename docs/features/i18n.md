# i18n & Translation — Feature Detail

## Purpose
Language switching (EN/MY/TH), translation helpers, snippet packs.

## Code Files

| Layer | File | Key symbols |
|-------|------|-------------|
| i18n | `skyadmin_pro/services/i18n.py` | `tr()`, `set_language()`, `_current_lang` |
| Translate | `skyadmin_pro/services/translate.py` | Translation helpers, `socket.timeout` mutation |
| Snippets | `skyadmin_pro/services/snippets.py` | `effective_text()`, `load_snippet_overrides()` |
| Config | `skyadmin_pro/config/__init__.py` | `CHECKLIST_TEMPLATES`, renewal template data |

## Architecture Decisions
- **`tr()` function**: wraps UI strings; returns original if translation unavailable.
- **Snippet packs**: versioned snapshot system (`snippet_versions` table).
- **Language setting**: stored in `settings` table as `ui_language`; applied on startup.
